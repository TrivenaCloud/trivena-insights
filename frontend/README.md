# Frontend

Vue 3 frontend for this Trivena app.

## Stack

- Vue 3 + Vue Router
- Tailwind CSS
- Trivena UI components

## Development

From the app root (with a running bench site):

```bash
cd frontend
yarn
yarn dev
```

The Vite dev server proxies API requests to your local site (usually port `8000`).

## Build

```bash
yarn build
```

Built assets are written into the app’s public folder for production.
