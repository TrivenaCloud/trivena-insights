# Trivena Insights

Analytics and reporting for Trivena Cloud.

## Hosted

Use on [Trivena Cloud](https://cloud.trivena.tech) — install from the Marketplace or include it when you create a Site.

## Self-hosted

```bash
bench get-app https://github.com/TrivenaCloud/trivena-insights.git
bench --site <site> install-app insights
```
